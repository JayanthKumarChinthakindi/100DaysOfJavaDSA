# Day 16 — Pattern Printing & Nested Loops

Day 16 of the #100DaysOfJavaDSA challenge focuses on **Pattern Printing and Nested Loops**.

The purpose of this practice day is to strengthen logical thinking by understanding the relationship between:

- Rows
- Columns
- Spaces
- Characters
- Nested loops
- Conditions

---

## 📚 Topics Covered

- Nested `for` loops
- Rows and columns
- Star patterns
- Number patterns
- Character patterns
- Increasing patterns
- Decreasing patterns
- Square patterns
- Hollow patterns
- Pyramid patterns
- Inverted pyramid
- Diamond pattern
- Floyd's Triangle
- Palindrome number pyramid
