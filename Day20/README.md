# Day 20 — Intermediate Array Problem Solving

Day 20 of the #100DaysOfJavaDSA challenge focuses on solving
intermediate array problems using Java.

The main goal is to improve:

- Logical thinking
- Array manipulation
- Problem decomposition
- Searching
- Frequency counting
- Mathematical reasoning
- Basic optimization thinking
