# Day 19 — Arrays + Methods + Problem Solving

Day 19 of the #100DaysOfJavaDSA challenge combines two important concepts:

- Arrays
- Methods
  The goal is to learn how to take an array-based problem, break it into smaller tasks, and implement each task using reusable methods.

## 🎯 Day 19 Objectives

By the end of Day 19, the following concepts should be understood:

- Passing arrays to methods
- Array traversal
- Array length
- Sum and average
- Maximum and minimum
- Linear search
- Counting occurrences
- Counting even and odd elements
- Reversing an array
- Checking whether an array is sorted
- Finding the second largest element
- Building a menu-driven array utility
