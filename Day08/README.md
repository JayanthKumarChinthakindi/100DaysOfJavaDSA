## 🧠 Important Concepts

### Parameter vs Argument

Parameter:
static int add(int a, int b)

Argument:
add(10, 20);

### void Method

static void greet() {
System.out.println("Hello");
}

### Return Method

static int add(int a, int b) {
return a + b;
}

### Method Overloading

add(int, int)
add(int, int, int)
add(double, double)
Same method name with different parameter lists.
