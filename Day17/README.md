# Day 17 — Advanced Pattern Practice

Day 17 of the #100DaysOfJavaDSA challenge focuses on **Advanced Pattern Printing, Nested Loops, Conditions, and Logic Building**.

Day 16 introduced the fundamentals of nested loops and basic patterns. Day 17 builds on those concepts by solving more complex and symmetrical patterns.

---

## 📚 Topics Covered

- Nested loops
- Multiple inner loops
- Spaces and alignment
- Star patterns
- Number patterns
- Character patterns
- Hollow patterns
- Symmetrical patterns
- Conditions inside nested loops
- Butterfly pattern
- Hollow triangle
- Hollow pyramid
- Hollow diamond
- Number pyramid
- Pascal's Triangle
- Binary triangle
- X pattern
- Plus pattern
- Character pyramid
- Palindrome character pyramid
- Number diamond
