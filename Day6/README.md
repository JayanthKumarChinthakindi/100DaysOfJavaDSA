## 🧠 Key Learning

The main rule of pattern printing:
**Outer Loop → Rows**
**Inner Loop → Columns / Elements**
Before writing the code, identify:

1. Number of rows
2. Number of elements in each row
3. What needs to be printed
4. How the number of elements changes
5. The relationship between row and column
