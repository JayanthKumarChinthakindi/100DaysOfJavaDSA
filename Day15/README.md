# Day 15 — Loops & Number-Based Problem Solving

Day 15 focuses on strengthening **loops, number manipulation, and logic-building skills** as part of the Practice Phase of the #100DaysOfJavaDSA challenge.

The goal is not just to write programs using loops, but to understand how loops can be used to break a problem into repeated steps.

---

## 📚 Topics Covered

- `for` loop
- `while` loop
- `do-while` loop
- Nested loops
- `break`
- `continue`
- Modulus operator `%`
- Integer division
- Digit extraction
- Counting digits
- Sum of digits
- Reverse of a number
- Palindrome numbers
- Factorial
- Prime numbers
- Factors
- GCD
- LCM
- Methods
- Boolean logic
- Problem decomposition
