# Day 18 — Methods & Modular Problem Solving

Day 18 of the #100DaysOfJavaDSA challenge focuses on **Methods and Modular Programming**.

The goal of today is to move from writing large blocks of code toward creating **small, reusable, and well-structured methods**.

---

## 📚 Topics Covered

- Methods
- Method declaration
- Method calling
- Parameters
- Arguments
- Return values
- `void` methods
- Boolean methods
- Multiple parameters
- `static` methods
- Local variable scope
- Method decomposition
- Method reuse
- Menu-driven programs
